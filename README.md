# Combat Drone - A Cool Desktop Pet
A cool looking and smooth feeling desktop pet that has commands.
## Features:
1. Double Click - Toggle Stop/Move
2. Right Click - Open Menu
3. Type Commands (Ensure active windowand just start typing) - "override" - Follows Mouse pointer.
                                                             - "stay" - Goes to bottom right corner and sits idle.
                                                             - "wander"- Turns the above both off.
                                                             - "die" - Quits the application after playing dying animation.
5. Draggable
